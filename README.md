Система учета заявок пользователей

Учебный проект с клиент-серверной архитектурой для управления заявками. 
Состоит из REST API сервера и десктопного WPF-клиента.

Реализованный функционал
- Поддержка полного цикла CRUD операций (создание, чтение, обновление, удаление).
- Асинхронное взаимодействие клиента с сервером.
- Хранение данных в JSON-файле с поддержкой кириллицы.

Технологии и архитектура
- Backend: C#, ASP.NET Core Web API
- Frontend: C#, WPF
- Архитектура: Многослойная, Dependency Injection, Repository Pattern

Запуск проекта
1. Установите несколько запускаемых проектов в решении (API и UI).
2. Запустите проект (F5).
3. Используйте графический интерфейс для создания, редактирования и удаления заявок.
